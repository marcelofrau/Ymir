--------------------------------------------------------------------------------
What this run proves
--------------------------------------------------------------------------------

PROVES:
- The boot reaches the main loop on the console (frames 0..610 presented, hr=00000000).
- The XAudio2 backend initializes and starts playback.
- The D3D12 context, the software framebuffer and the display texture are all created.
- The ImGui layer is initialized.
- The app enumerates ZERO joysticks and ZERO gamepads, and receives no joystick,
  gamepad, axis or button event at all.

DOES NOT PROVE:
- Anything about the gamepad mapping: there was never a device to map.
- Whether the virtual cursor moves: the app has no axis to read.
- Whether the Windows Gaming Input driver is functional on the console: the driver
  was never enabled (see the root cause below), so the WGI enumeration was never
  attempted.

--------------------------------------------------------------------------------
Root cause (found by reading the vendor after the run)
--------------------------------------------------------------------------------

vendor/SDL3-uwp/src/joystick/windows/SDL_windows_gaming_input.c:589

    if (!SDL_GetHintBoolean(SDL_HINT_JOYSTICK_WGI, false)) {
        return true;
    }

The WGI driver is opt-in in SDL. The hint defaults to "0"
(vendor/SDL3-uwp/include/SDL3/SDL_hints.h:2408-2415) and the app never set it, so
the joystick subsystem started with no working driver and enumerated nothing.

Fix (commit 1f098a91): SDL_SetHint(SDL_HINT_JOYSTICK_WGI, "1") before SDL_Init, under
#if YMIR_PLATFORM_UWP.
